# Facility Capital Markers package

This package is reserved for code that belongs to the existing
Facility Capital Markers application (`com.sab.carm.fcm`).

No Facility Capital Markers business/API implementation has been invented
in this ZIP because the actual FCM REST contract was not supplied.

The CARM integration implementation is under:
`com.sab.fcm.carm`

When integrating into the existing Facility Capital Markers source tree,
keep the existing FCM implementation under `com.sab.carm.fcm`.
